# 중국어 탐험대 · STAGE 02 이름표 마을 (3차시)

3차시 「你叫什么名字？」 복습 게임입니다. 문제 12개(종 9개 + 대나무 괴물 3문제), 그중 2개(약 17%)는 1·2차시 복습입니다.

| 구역 | 종 | 내용 |
| --- | --- | --- |
| 복습 숲 | 성조 암호 종 | (1차시) má·mà·mā 같은 세 소리 듣고 성조 번호 누르기 |
| | 공책 종 | (2차시) 对不起 → 没关系 |
| 이름 마을 | 질문 종 | 你 叫 什么 名字 순서대로 놓아 "이름이 뭐야?" 만들기 |
| | 낱말 종 | 我·你·什么·名字를 듣고 뜻 카드에 놓기 |
| | 첫 만남 종 | 你叫什么名字？ → 我叫小明。 |
| | 이름 빙고 종 | 我叫乐乐。를 듣고 1~4번 이름 카드 고르기 |
| 인사 다리 | 되묻기 종 | 你呢？의 뜻 |
| | 반가움 종 | 认识你很高兴！ 고르기 |
| | 이름 문화 종 | 王小明에서 성 찾기 |
| 언덕 | 대나무 괴물 | 이름 묻고 답하기 O/X 3문제 |

## 새로 바뀐 점
- 통통 버섯: 빨랐다 느렸다 하는 버섯, 깡충 뛰는 버섯, 하늘에서 떨어지는 버섯(떨어질 곳에 그림자와 ! 표시)
- 종·괴물 문제를 맞히거나 황금 대나무를 얻으면 화면이 빠르게 어두워졌다 밝아짐
- 구덩이, 세 단 계단, 움직이는 발판. 구덩이에 빠지면 그 구역 처음부터 다시 출발 (game-data.js의 `fallRespawn`으로 바꿀 수 있음: 'zone' / 'start' / 'bell')
- 보너스 별 점수: ? 상자(아래에서 머리로 치기) +20, 계단 꼭대기 황금 대나무 +50
- 선생님 화면(teacher.html): 누가 들어왔는지, 접속 중인지, 문제별 첫 선택·오답, 문제별 오답 비율, CSV 저장, 결과 삭제
- 반 순위표: 게임 중 🏆 버튼과 종료 화면에서 실시간 순위 (firebase-config.js의 `SHOW_RANKING`으로 끄기 가능)
